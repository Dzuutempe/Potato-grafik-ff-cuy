# Potato Patcher

Aplikasi Android untuk menerapkan patch tekstur low-poly ke data Free Fire / Free Fire MAX.

Semua file ada di satu folder. Saat build, `build.yml` menyusun ulang ke struktur Gradle otomatis.

Package game: com.dts.freefireth (Free Fire), com.dts.freefiremax (Free Fire MAX).
Repo ini tidak berisi tekstur; siapkan patch .zip sendiri yang cocok dengan versi game.
Android 13+ memblokir akses Android/data lewat pemilih folder.
